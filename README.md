# Coin-Pouch
Coin Pouch - Vault Hunters Addon

- Stores "unlimited" amounts of coins.
- Coins picked up will go directly into the pouch.
- Converts coins up and down like a compacting drawer. Always keeping the total amount of each and allowing to take any out.
- Combine with Echo Pog in an Anvil to add Soulbound. (This can be disabled in config)
- Combine with Soulbound Jewel in an Anvil to add Soulbound. (1.5.2+)
- Works with the Shop Pedestal. No need to take the coins out of the pouch. (Until 1.3.0)
- Works with all stations that use coins. No need to take the coins out of the pouch. (1.4.0+)
- Can be placed in Curious Slot (1.4.3+)
- Displays coins in all stations that use them. (1.5.0+)
- Pouch can be opened with a keybind. Default: P (1.5.0+)
- Works with Paradox doors. (1.5.1+)
- Displays coins in the crosshair when looking at Shop Pedestals and Paradox doors. (1.5.1+)
- Displays coins in the Inventory HUD overlay. (1.5.4+)
